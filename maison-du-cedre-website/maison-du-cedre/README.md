# Maison du Cèdre

Website starter for Maison du Cèdre.

## Files
- `index.html` — website structure and content
- `style.css` — visual design and responsive layout
- `script.js` — mobile navigation and contact-form demo
- `images/` — place your real bakery photos and logo here

## GitHub Pages
Repository Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

Replace the placeholder contact details and gallery backgrounds with the final business information and photographs before launch.
